# Trips & Scheduling

Solución .NET 11 en VB.NET para el microservicio Trips & Scheduling.

Ejecuta la API con `dotnet run --project src/Trips.Api`. Swagger está disponible en `/swagger` y el estado del servicio en `/health`.

Configura `ConnectionStrings:TripsDb` en `src/Trips.Api/appsettings.json` con la contraseña local de SQL Server antes de conectar la base de datos.
